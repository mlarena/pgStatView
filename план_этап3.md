# План Этапа 3: Web UI с D3.js

## 1. Цель этапа

Построить дашборд с интерактивными мультилинейными графиками D3.js v7: сравнение метрик между целевыми БД, выбор серий, tooltip, zoom/pan. Данные берутся из API Этапа 2 (`/api/databases`, `/api/metrics`).

**Результат этапа:** пользователь открывает главную страницу, видит список БД с их статусами, выбирает метрику и БД — получает график с историей, может наводить курсор для точных значений и приближать длинную историю.

**Зависимость:** Этап 2 завершён (есть история MetricPoint и API `/api/metrics` в D3-формате).

---

## 2. Структура фронтенда

Решение: **без SPA-фреймворка** — MVC Views + модульный vanilla JS (ES modules) + D3 v7 локально. Никакого webpack/vite: статика лежит в `wwwroot`, собирается вместе с проектом.

```
PgStatView.Web/wwwroot/
├── js/
│   ├── lib/
│   │   └── d3.v7.min.js            (локальная копия, без CDN)
│   ├── api.js                       (fetch-обёртка, JWT из sessionStorage)
│   ├── charts/
│   │   ├── chart-base.js            (svg, margins, scales, axes, resize)
│   │   ├── multi-line.js            (мультилинейный график — ядро этапа)
│   │   └── tooltip.js               (hover + bisector + floated div)
│   └── pages/
│       ├── dashboard.js             (главная: список БД, статусы)
│       └── compare.js               (страница сравнения с графиком)
└── css/
    └── site.css                     (поверх Bootstrap)
```

**Аутентификация в UI:** на Этапе 1 был JWT для API. На Этапе 3 добавляем cookie-аутентификацию для MVC-страниц (ASP.NET Core Cookie Auth параллельно с JWT для API), чтобы страницы защищались на сервере, а не только API.

## 3. Страницы

Главная страница этапа:

```
┌────────────────────────────────────────────────────────────┐
│ Метрика: [mean_exec_time ▾]  Период: [1ч|6ч|24ч|7д|30д]   │
```

## 4. Компонент multi-line.js — ядро этапа

### 4.1. API компонента

```javascript
// charts/multi-line.js
export function createMultiLineChart(containerSelector, options) {
  // options: { height, metricLabel, yFormatter, onPointHover }
  return {
    setData(seriesArray),   // [{id, label, color, points:[{time,value}]}]
    appendPoints(dbId, points),  // инкрементально (для live-обновления)
    toggleSeries(dbId, visible),
    setDomain([fromMs, toMs]),  // для zoom/brush
    destroy()
  };
}
```

### 4.2. Что внутри

- `scaleTime` по X, `scaleLinear` по Y (домен = [0, max × 1.1])
- `d3.axisBottom` с адаптивными тиками (зависят от ширины), `d3.axisLeft`
- `d3.line().curve(d3.curveMonotoneX)` — по path на серию, цвет из `series.color`
- `ResizeObserver` на контейнер → перерисовка с новой шириной
- Пустое состояние: «Нет данных за выбранный период»
- Готовые классы CSS для стилизации осей/сетки (горизонтальная сетка через `tickSize(-width)`)

### 4.3. Tooltip

- Невидимый `rect` поверх plot-area ловит `pointermove`
- `d3.bisector` находит ближайшую точку **в каждой видимой серии**
- Всплывающий `div` (позиционируется через `getBoundingClientRect`, не залезает за край):
  ```
  10:05:00
  ● prod-main   45.2 мс
  ● stage-01    12.1 мс
  ```
- Вертикальная линия-индикатор на позиции курсора
- На `pointerleave` — скрыть

### 4.4. Zoom / Pan

- `d3.zoom().scaleExtent([1, 200]).translateExtent(plotBounds)` на svg
- При зуме: пересчёт только `xScale` (Y остаётся авто по видимым точкам), перерисовка осей и path
- Кнопка «Reset zoom»
- **Отложенная задача (опционально):** brush для выбора диапазона с догрузкой данных с сервера (`setDomain` → новый fetch). Если времени мало — только zoom по загруженному окну.

### 4.5. Live-обновление (polling)

```javascript
// pages/compare.js
let timer = null;
function startAutoRefresh(ms) {
  clearInterval(timer);
  timer = setInterval(async () => {
    const from = lastPointTime + 1s;
    for (const dbId of visibleSeries) {
      const data = await api.getMetrics({ dbIds: [dbId], from });
      chart.appendPoints(dbId, data.series[0].points);
    }
  }, ms);
}
```

- `d3.transition()` 300 мс при добавлении точек — линия «растёт» плавно
- Остановка таймера при уходе со страницы (`dispose`), чтобы не течь по памяти

## 5. API-клиент (api.js)

```javascript
const api = {
  async getDatabases()        { ... }   // GET /api/databases
  async getMetrics(params)    { ... }   // GET /api/metrics?...
  async getSnapshot(dbId)     { ... }   // GET /api/snapshot/{dbId}
  async getInterval()         { ... }
  async setInterval(seconds)  { ... }
};
```

- Единая обработка 401 → редирект на страницу логина
- Единая обработка ошибок → toast-уведомление (свой мини-компонент)
- `AbortController` на каждый запрос: при смене периода старый запрос отменяется (защита от гонок)
