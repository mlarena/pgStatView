# План Этапа 5: Визуализация планов (PEV2)

## 1. Цель этапа

Заменить сырой JSON-вывод планов на интерактивную визуализацию через PEV2 (PostgreSQL EXPLAIN Visualizer 2). Добавить сравнение двух планов бок о бок с цветовой подсветкой различий.

**Результат этапа:** пользователь открывает план выполнения из `/queries/{queryHash}` и видит красивое дерево с цветовой кодировкой (время, стоимость, параллелизм). На странице сравнения два PEV2-древесных дерева рядом, различия подсвечены.

**Зависимость:** Этапы 1–4 завершены (API `/api/explain` отдаёт JSON-план).

---

## 2. Что такое PEV2

[PEV2](https://github.com/explainext/pev2) — open-source JS-библиотека для рендеринга `EXPLAIN (FORMAT JSON)` в интерактивное дерево. Включает:
- Цветовую кодировку (высокое время = красный, низкое = зелёный)
- Масштабирование и навигацию по дереву
- Всплывающие подсказки с деталями
- Поддержку параллельных планов

Интеграция: **единый JS-файл + CSS**, собирается в `wwwroot`. Никакого npm — просто копируем бандл.

## 3. Страница плана выполнения

### 3.1. Детальная страница — `/queries/{queryHash}` (обновлённая)

**До:** кнопка «EXPLAIN» → `<pre>` с JSON
**После:** кнопка «EXPLAIN» → PEV2-контейнер `<div id="explain-chart">`

```
┌────────────────────────────────────────────────────────────┐
│  SELECT * FROM orders WHERE id = $1                        │
│  Таблицы: [orders]  [users]                                │
│                                                            │
│  ┌──────────────────────────────────────────────────────┐  │
│  │                  PEV2 дерево                          │  │
│  │  ┌─ Index Scan ─┐                                   │  │
│  │  │   Index Cond  │                                   │  │
│  │  │   Planning: 0.05ms                             │  │
│  │  └───────────────┘                                   │  │
│  │                                                      │  │
│  │  [Zoom +] [Zoom -] [Reset]  [Copy JSON]  [PDF]    │  │
│  └──────────────────────────────────────────────────────┘  │
│                                                            │
│  [Сравнить с другой БД]  [Сохранить план]                  │
└────────────────────────────────────────────────────────────┘
```

- Кнопки: Zoom, Reset, Copy JSON (исходный JSON-план), Save (сохранить в мета-БД)
- PEV2 рендерит дерево в `<div>` через `new ExplainChart(data).render(document.querySelector("#explain-chart"), false)`
- `false` = не показывать Summary (пока)

**До:** две колонки с `<pre>` JSON
**После:** две колонки с PEV2-деревьями, различия подсвечены

```
┌──────────────────────────────────┐ ┌──────────────────────────────────┐
│  prod-main                       │ │  stage-01                         │
│  ┌─ Seq Scan ─────────────────┐  │ │  ┌─ Index Scan ────────────────┐  │

```

- Каждый PEV2-экземпляр получает свой `<div>`
- Кнопка «Highlight diffs» (опционально): если дерево имеет одинаковую структуру — подсвечивает узлы с >50% разницей по времени

## 4. Сохранение планов в мета-БД

### 4.1. Модель ExplainPlan

```csharp
public class ExplainPlan
{
    public long Id { get; set; }
    public string MonitoredDatabaseId { get; set; }
    public string QueryHash { get; set; }
    public string QueryText { get; set; }
    public string PlanJson { get; set; }   // EXPLAIN (FORMAT JSON)
    public DateTime CapturedAt { get; set; }
}
```

**Индексы:**
- `IX_ExplainPlan_MonitoredDatabaseId_QueryHash_CapturedAt`

### 4.2. API: сохранение и список планов

| Endpoint | Метод | Описание |
|----------|-------|----------|
| `/api/plans` | POST | Сохранить план |
| `/api/plans` | GET | Список сохранённых планов |
| `/api/plans/{id}` | GET | Получить сохранённый план (JSON) |

- При сохранении: если план с таким `dbId` + `queryHash` уже есть — не дублируем (или обновляем)
- Список: `dbId`, `queryText`, `capturedAt` — можно сравнить сохранённые планы

## 5. Детальная разбивка задач

### Задача 1. Интеграция PEV2 в проект (1.5 часа)

- Скачать бандл PEV2: `pev2.min.js` и `pev2.min.css` с GitHub releases
- Положить в `wwwroot/js/lib/` и `wwwroot/css/`
- В `_Layout.cshtml` подключить:
  ```html
  <link href="~/css/pev2.min.css" rel="stylesheet" />
  <script src="~/js/lib/pev2.min.js"></script>
  ```
- Создать `wwwroot/js/charts/explain-chart.js`:
  ```javascript
  export function renderExplain(container, planJson) {
    const data = JSON.parse(planJson);
    const chart = new ExplainChart(data);
    chart.render(container, false);  // false = без summary
  }
  ```

**Результат:** на странице есть `<div id="explain-chart">`, JS-функция рендерит JSON в дерево.

- Кнопки: Zoom +/−, Reset, Copy JSON

**Результат:** JSON-план → интерактивное PEV2-дерево.

**Результат:** планы сохраняются, можно загрузить позже.

### Задача 5. Сравнение планов с PEV2 (1.5 часа)

- `/explain/compare`: две колонки `<div class="pev2-panel">`
- Двойной fetch `/api/explain?dbId=...` для двух БД
- Два вызова `renderExplain()` — по одной на колонку
- Кнопка «Highlight diffs» (опционально): простейшая логика — сравнить `Actual Total Time` у корневых узлов, если разница >50% — подсветить зелёным/красным

**Результат:** два PEV2-дерева рядом, визуальное сравнение.

### Задача 6. Сохранение при открытии (1 час)

- Кнопка «История планов» → открывает `/plans` (список сохранённых планов с датами)

**Результат:** план сохраняется автоматически при просмотре.
