## 2. SignalR — real-time обновления

### 2.1. Архитектура

```
CollectionBackgroundService (сбор завершен)
    │
    ▼
SignalR Hub → BroadcastNewMetrics(dbId, points)
    │
    ▼
Клиентские подписки:
    - Dashboard: обновление статусов БД
    - Compare page: новые точки на графике
    - Query detail: история конкретного запроса
```

**Подход:**
- Сервер не ждёт подписчиков — если кто-то подписан, пушит. Если никто не подписан — просто игнорируется.
- Клиент переподключается автоматически (SignalR встроенный retry: 5s, 10s, 30s, max 5 мин).
- На Этапе 6 не делаем «live-режим по умолчанию» — только опциональный toggle.

### 2.2. Hub

```csharp
public class MetricsHub : Hub
{
    private readonly IMetricsPublisher _publisher;

    public MetricsHub(IMetricsPublisher publisher)
    {
        _publisher = publisher;
    }

    public async Task SubscribeToDb(string dbId)
    {
        await Groups.AddToGroupAsync(Context.ConnectionId, dbId);
    }

    public async Task UnsubscribeFromDb(string dbId)
    {
        await Groups.RemoveFromGroupAsync(Context.ConnectionId, dbId);
    }
}
```

### 2.3. IMetricsPublisher (интерфейс)

```csharp
public interface IMetricsPublisher
{
    Task NotifyNewPoints(string dbId, List<MetricPointDto> points);
}
```

Реализация — `SignalRMetricsPublisher` внутри `PgStatView.Web`, инстансирует `IHubContext<MetricsHub>`.

### 2.4. Вызов из Collector

```csharp
// В CollectionBackgroundService после сохранения точек
foreach (var result in results) {
    if (result.Success && result.Points.Any()) {
        await _publisher.NotifyNewPoints(result.DbId, result.Points);
    }
}
```

### 2.5. Клиент JS

```javascript
// wwwroot/js/hub.js
import * as signalR from '@microsoft/signalr';

export function createMetricsHubConnection(connectionString) {
  const connection = new signalR.HubConnectionBuilder()
    .withUrl('/metricsHub', {
      skipNegotiation: true,
      transport: signalR.HttpTransportType.WebSockets |
                 signalR.HttpTransportType.ServerSentEvents |
                 signalR.HttpTransportType.LongPolling
    })
    .withAutomaticReconnect()
    .build();

  connection.on('ReceiveNewPoints', (dbId, points) => {
    // добавить точки на график
    chart.appendPoints(dbId, points);
  });

  connection.start().then(() => {
    connection.invoke('SubscribeToDb', 'prod-main');
  });

  return connection;
}
```

**Важно:** SignalR в ASP.NET Core работает с CORS. Настроить:
- `builder.Services.AddSignalR()`
- `app.MapHub<MetricsHub>("/metricsHub")`
- CORS: разрешить origin фронтенда (если фронтенд на том же origin — проблем нет)

**Важно:** мета-БД — SQLite, данные хранятся в файле. volume `pgdata` мапится на контейнер. Бэкап — просто копирование файла.

## 4. Health checks

### 4.1. Приложение

```csharp
// Program.cs
builder.Services.AddHealthChecks();

app.MapHealthChecks("/health");
app.MapHealthChecks("/health/ready", new HealthCheckOptions {
    Predicate = _ => true
});
```

### 4.2. Проверка целевых БД

```csharp
// HealthChecks/TargetDbHealthCheck.cs
public class TargetDbHealthCheck : IHealthCheck
{
    private readonly IMetaContext _context;

    public async Task<HealthCheckResult> CheckHealthAsync(...) {
        var dbs = await _context.MonitoredDatabases.Where(d => d.IsEnabled).ToListAsync();
        var results = new List<HealthCheckResult>();
        foreach (var db in dbs) {
            try {
                using var conn = new NpgsqlConnection(db.ConnectionString);
                await conn.OpenAsync();
                results.Add(HealthCheckResult.Healthy($"Connected to {db.DisplayName}"));
            } catch {
                results.Add(HealthCheckResult.Unhealthy($"Failed to connect to {db.DisplayName}"));
            }
        }
        return results.Any(r => r.Status == HealthCheckResult.Unhealthy)
            ? HealthCheckResult.Degraded(string.Join("; ", results))
            : HealthCheckResult.Healthy(string.Join("; ", results));
    }
}
```

### 4.3. Response

```json
{
  "status": "Healthy",
  "checks": [
    { "name": "SQLite", "status": "Healthy" },
    { "name": "prod-main", "status": "Healthy" },
    { "name": "stage-01", "status": "Healthy" }
  ]
}
```
