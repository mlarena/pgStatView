# План Этапа 1: Мета-БД + Управление подключениями

## 1. Цель этапа

Реализовать основу приложения: структуру решения, мета-БД (SQLite + EF Core), CRUD для целевых БД, базовую авторизацию (пользователи, без ролей), API для фронтенда и настройку интервала сбора метрик.

**Результат этапа:** можно добавлять целевые PostgreSQL-серверы, видеть их список в API, система аутентифицирует пользователей, интервал сбора настраивается через конфиг/UI.

## 3. Модели данных

### 3.1. MonitoredDatabase

Целевой PostgreSQL-сервер для мониторинга.

```csharp
public class MonitoredDatabase
{
    public string Id { get; set; }              // "prod-main", "stage-01" (GUID или кастомный slug)
    public string DisplayName { get; set; }     // "Production Main"
    public string Host { get; set; }            // "pg-prod.internal"
    public int Port { get; set; }               // 5432
    public string DatabaseName { get; set; }    // "app"
    public string Username { get; set; }        // "monitor"
    public string Password { get; set; }        // ХРАНИТСЯ ОТКРЫТО (по требованию)
    public string Color { get; set; }           // "#e74c3c" для графиков
    public bool IsEnabled { get; set; }         // true/false
    public DateTime CreatedAt { get; set; }     // UTC
    public DateTime? UpdatedAt { get; set; }    // UTC
    
    // Навигационные свойства
    public ICollection<Snapshot> Snapshots { get; set; } = new List<Snapshot>();
    public ICollection<MetricPoint> MetricPoints { get; set; } = new List<MetricPoint>();
}
```

**Индексы:**
- `IX_MonitoredDatabase_Id` — уникальный
- `IX_MonitoredDatabase_IsEnabled` — для быстрого фильтра

### 3.2. Snapshot

Полный снимок `pg_stat_statements` на момент времени.

```csharp
public class Snapshot
{
    public long Id { get; set; }
    public string MonitoredDatabaseId { get; set; }
    public DateTime CapturedAt { get; set; }     // UTC
    public string RawData { get; set; }           // JSON-строка
    
    // Навигационное свойство
    public MonitoredDatabase? Database { get; set; }
}
```

**Индексы:**
- `IX_Snapshot_MonitoredDatabaseId_CapturedAt` — составной

### 3.3. MetricPoint

Точка метрики для построения графиков.

```csharp
public class MetricPoint
{
    public long Id { get; set; }
    public string MonitoredDatabaseId { get; set; }
    public DateTime CapturedAt { get; set; }      // UTC
    public long QueryId { get; set; }             // из pg_stat_statements
    public long Calls { get; set; }
    public double TotalExecTime { get; set; }     // мс
    public double MeanExecTime { get; set; }      // мс
    public long Rows { get; set; }
    public string QueryText { get; set; }         // текст запроса
    
    // Навигационное свойство
    public MonitoredDatabase? Database { get; set; }
}
```

**Индексы:**
- `IX_MetricPoint_MonitoredDatabaseId_CapturedAt`
- `IX_MetricPoint_QueryId`

### 3.4. User

Системный пользователь для доступа к веб-интерфейсу.

```csharp
public class User
{
    public int Id { get; set; }
    public string Username { get; set; }          // уникальный логин
    public string PasswordHash { get; set; }      // хеш пароля (BCrypt)
    public DateTime CreatedAt { get; set; }       // UTC
    public DateTime? LastLoginAt { get; set; }    // UTC
}
```

**Индексы:**
- `IX_User_Username` — уникальный

### 3.5. CollectionInterval

Настройка интервала сбора метрик.

```csharp
public class CollectionInterval
{
    public int Id { get; set; }                    // всегда 1
    public int IntervalSeconds { get; set; }       // по умолчанию 60
    public DateTime UpdatedAt { get; set; }        // UTC
}
```

## 4. API Endpoints

### 4.1. Auth (AuthController)

| Endpoint | Метод | Описание |
|----------|-------|----------|
| `/api/auth/register` | POST | Регистрация пользователя |
| `/api/auth/login` | POST | Вход, возврат JWT-токена |

**Request/Response:**
```json
// POST /api/auth/register
{ "username": "admin", "password": "secret123" }
→ 201 Created

// POST /api/auth/login
{ "username": "admin", "password": "secret123" }
→ { "token": "eyJ...", "expiresAt": "2026-10-23T12:00:00Z" }
```

### 4.2. Databases (DatabasesController)

| Endpoint | Метод | Описание |
|----------|-------|----------|
| `/api/databases` | GET | Список всех БД |
| `/api/databases` | POST | Создание новой БД |
| `/api/databases/{id}` | GET | Детали одной БД |
| `/api/databases/{id}` | PUT | Обновление БД |
| `/api/databases/{id}` | DELETE | Удаление БД |
| `/api/databases/{id}/test` | POST | Проверка соединения с БД |

**GET `/api/databases` — ответ:**
```json
[
  {
    "id": "prod-main",
    "displayName": "Production Main",
    "host": "pg-prod.internal",
    "port": 5432,
    "databaseName": "app",
    "username": "monitor",
    "color": "#e74c3c",
    "isEnabled": true,
    "createdAt": "2026-10-23T10:00:00Z",
    "lastSnapshotAt": "2026-10-23T10:05:00Z"
  }
]
```

**POST `/api/databases/{id}/test` — ответ:**
```json
{
  "success": true,
  "message": "Connected successfully",
  "postgresqlVersion": "16.1",
  "pgStatStatementsAvailable": true
}
```

### 4.3. Collection Interval (CollectionIntervalController)

| Endpoint | Метод | Описание |
|----------|-------|----------|
| `/api/collection-interval` | GET | Текущий интервал |
| `/api/collection-interval` | PUT | Обновление интервала |

**GET `/api/collection-interval` — ответ:**
```json
{
  "intervalSeconds": 60,
  "updatedAt": "2026-10-23T10:00:00Z"
}
```

**PUT `/api/collection-interval` — request:**
```json
{ "intervalSeconds": 120 }
→ 200 OK
```
Фоновый сборщик перезапустится с новым интервалом без перезагрузки приложения.

## 5. Детальная разбивка задач

### Задача 1. Скелет решения (1 час)

**Что сделать:**
- `dotnet new sln -n PgStatView`
- `dotnet new classlib -n PgStatView.Core -o PgStatView.Core`
- `dotnet new classlib -n PgStatView.Meta -o PgStatView.Meta`
- `dotnet new classlib -n PgStatView.Collector -o PgStatView.Collector`
- `dotnet new web -n PgStatView.Web -o PgStatView.Web`
- `dotnet new xunit -n PgStatView.Tests -o PgStatView.Tests`
- `dotnet sln add` всех проектов
- Добавить references: Web → Meta, Collector, Core; Meta → Core; Collector → Core

**Результат:** решение собирается, все проекты существуют.

---

### Задача 2. Модели Core + DTOs (1 час)

**Что сделать:**
- Создать файлы моделей в `PgStatView.Core/Models/`:
  - `MonitoredDatabase.cs`
  - `Snapshot.cs`
  - `MetricPoint.cs`
  - `User.cs`
  - `CollectionInterval.cs`
- Создать DTO в `PgStatView.Core/DTOs/`:
  - `MonitoredDatabaseDto.cs` (request/response)
  - `LoginDto.cs`, `RegisterDto.cs`
  - `CollectionIntervalDto.cs`
- Добавить nuget-пакеты: `Microsoft.Extensions.Identity.Core` (BCrypt для хеширования паролей)

**Результат:** все модели и DTO скомпилированы, валидация через DataAnnotations.

---

### Задача 3. Meta DbContext + Миграции (1.5 часа)

**Что сделать:**
- В `PgStatView.Meta/Data/MetaDbContext.cs`:
  - Наследование от `DbContext`
  - `DbSet<T>` для всех сущностей
  - `OnConfiguring` — SQLite, строка подключения из конфига
  - `OnModelCreating` — fluent API: индексы, связи, конфигурация типов
- В `PgStatView.Meta/Data/DbInitializer.cs`:
  - Создание базы при старте (если не существует)
  - Seed-пользователь (если первый запуск)
- Добавить nuget-пакеты: `Microsoft.EntityFrameworkCore.Sqlite`, `Microsoft.EntityFrameworkCore.Tools`
- Создать миграцию: `dotnet ef migrations add InitialCreate --project PgStatView.Meta`

**Результат:** база SQLite создаётся автоматически, схема соответствует моделям.

---

### Задача 4. CRUD сервисы в Meta (1.5 часа)

**Что сделать:**
- `PgStatView.Meta/Services/MonitoredDatabaseService.cs`:
  - `GetAllAsync()` — список всех БД с `LastSnapshotAt`
  - `GetByIdAsync(string id)` — одна БД
  - `CreateAsync(MonitoredDatabaseDto dto)` — создание
  - `UpdateAsync(string id, MonitoredDatabaseDto dto)` — обновление
  - `DeleteAsync(string id)` — удаление (физическое, без soft-delete на этом этапе)
- `PgStatView.Meta/Services/UserService.cs`:
  - `RegisterAsync(string username, string password)` — с BCrypt-хешированием
  - `AuthenticateAsync(string username, string password)` — возврат пользователя
- `PgStatView.Meta/Services/CollectionIntervalService.cs`:
  - `GetAsync()` — текущий интервал
  - `UpdateAsync(int seconds)` — обновление (range check: 10–3600 сек)

**Результат:** все сервисы скомпилированы, DI-регистрация готова.

  - SQLite connection string (`Data Source=pgstatview.db`)

**Результат:** все endpoints работают, POSTMAN-тесты проходят.

### Задача 6. JWT Authentication (1 час)

**Что сделать:**
- В `Program.cs`:
  - Настроить `AddJwtBearer`
  - Секрет ключ — строка из `appsettings.json` (для продакшена — env var)
  - Алгоритм: `HS256`
- Генерация токена в `AuthController.Login`:
  - `JwtSecurityTokenHandler`
  - Claims: `sub` = username, `exp`, `iat`
  - TTL: 24 часа
- Базовая защита: `[Authorize]` на контроллерах Databases, CollectionInterval

**Результат:** неавторизованные запросы получают 401, авторизованные — 200.
